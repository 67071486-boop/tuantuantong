一、前言

欢迎您使用由鸡蛋铺（以下简称“我们”）提供的实名认证服务。我们深知个人信息对您的重要性，并会尽全力保护您的个人信息安全可靠。本《实名认证服务隐私协议》（以下简称“本协议”）旨在向您清晰、透明地说明我们在您使用本服务时，如何收集、使用、存储、共享及保护您的个人信息，以及您享有的相关权利。

请您在使用本服务前，务必仔细阅读并充分理解本协议全部内容。特别是涉及敏感个人信息处理、信息保存期限及您权利行使的条款，我们将以加粗形式提示您重点关注。若您不同意本协议的任何内容，请立即停止使用本服务；若您选择继续使用，即表示您已充分理解并自愿接受本协议的全部约束。

二、服务前提与适用范围

  1. 本服务仅限鸡蛋铺授权的系统商家 —（以下简称“本商家”）内部使用，核心用途为核实该商家雇员的真实身份，保障系统操作安全与业务合规。
  2. 本服务不提供面向公众的开放注册功能，仅针对入职商家的在职或拟入职雇员开放。若系统变量渲染异常导致商家名称显示不完整，请以您实际入职的商家主体为准。

三、我们收集的个人信息类型

为完成实名认证，我们会遵循合法、正当、必要原则，收集以下信息：

  1. 基础身份信息（必选）：您的姓名、身份证号码。该信息是完成实名核验的基础数据，若您拒绝提供，将无法使用本服务。
  2. 人脸生物识别信息（可选/敏感个人信息）：仅当入职商家在系统中明确开启人脸认证功能时，我们才会收集您的人脸图像数据用于身份比对。该信息属于敏感个人信息，非实名认证的强制要求；若您拒绝提供，仍可通过基础身份信息完成认证，不影响核心功能使用。
  3. 设备与安全信息（可选）：设备型号、操作系统版本、IP地址、网络状态等。该信息仅用于风控校验、防止身份冒用及服务优化，不涉及个人身份识别。

四、敏感个人信息特别告知

若您所在商家启用人脸认证，请您特别注意：

  • 处理目的：仅用于高安全等级场景下的身份核验，确保操作人员与认证主体一致，防范账号盗用、违规操作等风险。
  • 处理方式：人脸图像数据仅用于实时比对，不会用于任何其他商业用途或训练模型。
  • 单独同意：您需要通过独立的确认动作（如单独勾选、弹窗确认）明示同意我们处理您的人脸信息，该同意包含了基础实名认证同意。
  • 撤回同意：您可随时通过本协议第十条约定的渠道撤回对人脸信息处理的同意，撤回后我们将停止采集并删除已存储的人脸数据。

五、个人信息的使用目的

我们仅在实现服务目的所必需的最小范围内使用您的个人信息，具体包括：

  1. 完成入职商家的雇员身份真实性核验；
  2. 为后续技术服务支持、订单责任溯源、安全审计提供依据；
  3. 调查和处理涉嫌违法违规的行为（包括但不限于账号盗用、非法交易、恶意破坏系统安全等），保护入职商家的合法权益；
  4. 履行法律法规规定的义务。

我们承诺不会将您的个人信息用于上述目的之外的任何场景，也不会进行自动化决策。

六、服务性质与责任划分

1. 技术服务定位：鸡蛋铺仅作为实名认证技术的提供方，为商家内部雇员入职提供身份核验的技术支持与系统工具。我们不对入职商家的经营管理行为、用工合法性、业务合规性等进行实质审查，亦不参与其内部人事管理决策。

2. 商家主体责任：本商家应确保其使用本服务的目的、方式、范围均符合法律法规要求，并已依法取得雇员的充分授权与同意。因商家超出授权范围内使用本服务、未履行告知同意义务、或将本服务用于违法违规活动所产生的一切法律责任与纠纷，均由您入职的商家独立承担。

3. 平台免责边界：在鸡蛋铺已履行法律法规规定的技术安全保障义务、且对商家的违法违规行为不存在明知或应知而未采取必要措施的情形下，鸡蛋铺不因商家的独立行为承担连带责任。

4. 违规处置权：若我们发现或收到举报证实本商家存在滥用本服务、侵犯雇员权益或违反法律法规的行为，我们有权立即暂停或终止向其提供服务，并依法向有关主管部门报告。

七、信息共享与披露限制

未经您的明示同意，我们不会将您的实名信息共享给入职商家以外的任何第三方，但以下情形除外：

  1. 法定披露：根据适用法律、法规、监管要求或司法/行政机关的强制性命令；
  2. 权益保护：为应对紧急情况下的人身、财产安全威胁，或调查处理严重违规行为以保护入职商家及用户的合法权益；
  3. 技术支撑：向提供身份核验能力的第三方服务商共享必要信息，且我们会通过协议约束其严格保密并限定使用范围。

八、信息安全保障措施

我们采取符合业界标准的安全防护措施保护您的个人信息，包括：

  • 数据传输全程加密，人脸信息等敏感数据存储采用加密算法；
  • 实行严格的访问权限控制与操作审计，仅限授权人员按需访问；
  • 定期开展安全评估与漏洞修复，建立应急响应机制。

若发生个人信息安全事件，我们将按照法律法规要求及时向您告知事件基本情况、可能影响、已采取措施及补救建议。尽管我们已尽合理努力，但互联网环境并非绝对安全，敬请理解。

九、信息保存期限与删除规则

  1. 我们仅在实现处理目的所必要的最短期限内保留您的个人信息。
  2. 人脸图像数据：保存期限不超过您在职期间及离职后合理追溯期，最长不超过2年；超出期限或您撤回同意后，我们将在30日内自动删除或匿名化处理。
  3. 基础身份信息：保存至您从入职商家离职且相关责任追溯期满后，届时将依法删除或匿名化。
  4. 法律法规另有规定保存期限的，从其规定。

十、未成年人保护

本服务不面向未满18周岁的未成年人开放。我们不会故意收集未成年人的个人信息。若您发现我们误收集了未成年人信息，请通过鸡蛋铺官方任何渠道的客服联系我们提出请求，我们将按现行法律法规处理您的诉求。

  3. 删除权：符合法定删除情形时要求我们删除信息；
  4. 撤回同意权：撤回对人脸信息等敏感信息的处理同意，撤回不影响此前基于同意已进行的处理效力；
  5. 注销账户权：终止实名认证服务并要求删除相关信息；
  6. 投诉举报权：对我们的信息处理行为提出质疑。

我们将在收到请求后15个工作日内响应，因合理原因无法按时响应的，将向您说明情况。
